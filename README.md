# GECİKME MAZERET FABRİKASI

## Resmi Tanım
Bu repository, insanlık tarihinin en büyük sorunlarından birine — yani "geç kaldım" demenin bilimsel çözümüne — adanmıştır. 
Tamamen çalışan, tamamen gereksiz, tamamen absürt bir Python scriptidir.

## Nasıl Çalışır?
1. Terminali aç
2. `python mazeret_fabrikasi.py` yaz
3. Ciddiyetle bekle
4. Çıkan mazereti patronuna gönder (veya gönderme, daha iyi)
5. Tekrar et, sonsuza kadar

## Özellikler
- %100 gerçek Python kodu
- %0 gerçek mazeret
- Rastgele seçim algoritması (random.choice diye bir şey duydunuz mu?)
- Dramatik bekleme süresi (1.5 saniye)
- Emoji desteği (çünkü neden olmasın)

## Uyarı
Bu mazeretleri gerçek hayatta kullanırsanız sorumluluk tamamen size aittir. 
Kod yazarı "ben sadece eğlendim" diyerek kaçar.

## Lisans
MIT değil, "İstediğini yap, ama mazeretini kendin bul" lisansı.

## Katkı
Katkıda bulunmak istiyorsanız, daha da saçma bir mazeret ekleyin ve pull request açın. 
Reddedilme ihtimaliniz %99'dur, ama denemek serbesttir.
